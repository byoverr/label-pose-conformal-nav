# Результаты

Все файлы здесь создают скрипты из `scripts/` (точные команды — в `Makefile`); руками ничего не правилось. Папки названы
по схеме `<что>_<задачи>_<вариант>`. Главное для чтения — `tables/` и `figures/`, остальное — сырые данные по сценам.

## Сводки

| Папка | Что внутри |
|---|---|
| `tables/` | сводные CSV: покрытие (`coverage*.csv`), миссии (`missions_*.csv`), риск (`risk_*.csv`, `crc_*.csv`), исполнение (`execution.csv`), проверки на отладочной сцене (`cascade_dev.csv`, `frame_vote_dev.csv`) |
| `figures/` | рисунки; `figures/ru/` — русские версии для статьи и отчёта, остальные — диагностика, которую строят скрипты анализа |

## Сырые данные по сценам

**Промахи** — `scores*/<сцена>.csv`: расстояние промаха каждого варианта калибровки для каждого уровня дрейфа и
каждой реализации.

| Вариант | Восприятие или поза |
|---|---|
| `scores` | основной: YOLO-World v2-s, рамка + глубина |
| `scores_x`, `scores_yoloe` | YOLO-World v2-x, YOLOE-v8-S |
| `scores_ens_max`, `_ens_mean`, `_ens_vote2` | объединение трёх детекторов: максимум, среднее, второе по величине |
| `scores_cascade` | объединение, проверенное CLIP |
| `scores_sam` | маски MobileSAM вместо рамок |
| `scores_closed5` | закрытый словарь из пяти классов |
| `scores_extra` | области классов, дорощенные на 15–30 см |
| `scores_vo`, `scores_slam`, `scores_slam_ens_max` | реальная одометрия, SLAM с замыканиями, SLAM + ансамбль |
| `scores_hm3d` | сцены HM3D (перенос) |

**Миссии** — `missions_<задачи>_<вариант>/<сцена>.csv` (исход каждой задачи для каждой калибровки) и
`params_<сцена>.csv` (запасы, откалиброванные по остальным сценам). Задачи: `pb` — трудные («проезд мимо» растения или
велосипеда), `rand` — случайные; папка `missions` без суффикса и `missions_closed5` — три запретных класса. Варианты
те же, что у промахов, плюс уровень риска: `_a005`, `_a02`, `_a03` — α = 0,05 / 0,2 / 0,3.

**Риск** — `risk_<задачи>/`: пути, построенные с запасами 0–2 м, и их зазоры до областей классов; `cal_<сцена>.csv` —
калибровочные промахи остальных сцен. По ним считаются «риск вместо отказа» и гарантия на миссии. `risk_slam_*` и
`risk_ens_*` — то же с позами SLAM и с ансамблем детекторов.

**Исполнение** — `exec_<задачи>/`: та же сетка путей, каждый путь пройден 20 раз с продолжающимся дрейфом позы.
